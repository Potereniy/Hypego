# Перед публичным запуском

- [ ] Установить сильный `AUTH_SECRET` и проверить, что `.env` отсутствует в git.
- [ ] Создать Neon production database и применить `schema.sql`.
- [ ] Создать владельца через `npm run admin:create` с новым паролем.
- [ ] Настроить Vercel Blob, если включены загрузки изображений.
- [ ] Заполнить каталог реальными ценами, валютами, наличием и условиями.
- [ ] Выбрать платёжного провайдера, проверить поддержку вашей юрисдикции и валют, добавить подписанную проверку webhook и idempotency до включения пополнений.
- [ ] Настроить Minecraft bridge на закрытом сервере, проверить команды и поведение при повторных доставках.
- [ ] Настроить резервные копии Neon, мониторинг ошибок, rate limits и политику конфиденциальности.
- [ ] Протестировать регистрацию, вход, права ролей, выдачу/снятие ролей, начисление/списание зарплаты, магазин и отказ платёжной системы.
